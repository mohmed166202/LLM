# Semantic Book Search & Recommendation API with RAG

This project implements a powerful semantic search and recommendation system for products (specifically tailored for books in the current implementation), leveraging sentence embeddings, FAISS for efficient searching, and Google's Gemini API for Retrieval-Augmented Generation (RAG) based recommendations and chat interactions.

## Overview

The system consists of several key components:

1.  **Embedding Generation (`c:\Users\moham\Downloads\LLM\embeddings.py`):**
    *   Connects to a MySQL database (`PrintradoProducts` table).
    *   Uses the `sentence-transformers` library (`all-MiniLM-L6-v2` model) to generate vector embeddings for product names and categories.
    *   Stores these embeddings (as JSON strings) back into the database in `name_embedding` and `category_embedding` columns. This script needs to be run once initially or whenever the product data changes significantly.

2.  **Main Search & Chat API (`c:\Users\moham\Downloads\LLM\search_api_with_sales.py`):**
    *   A FastAPI application providing the core search and chat functionality.
    *   Loads product information and embeddings from the database.
    *   Builds (or loads from disk) a FAISS index for fast vector similarity searches.
    *   **`/search` endpoint:**
        *   Takes a user query.
        *   Converts the query to an embedding.
        *   Performs a semantic search using the FAISS index to find relevant products.
        *   Retrieves the top `k` initial results.
        *   Re-ranks these results based on `total_items_sold` (popularity).
        *   Uses the Gemini API (RAG) to generate context-aware recommendations for the top results based on the original query and product details.
    *   **`/chat` endpoint:**
        *   Takes a user query.
        *   Uses the Gemini API to determine the user's intent (e.g., general chat vs. book request).
        *   If it's a book request (`BOOK_REQUEST`), it triggers the `/search` logic.
        *   If it's general conversation, it provides a friendly response generated by Gemini.
    *   Includes logging, error handling, and CORS configuration for frontend integration.
    *   Also includes a `/query-to-vector` endpoint for debugging or specific use cases.

3.  **Utility Query-to-Vector API (`c:\Users\moham\Downloads\LLM\query_to_vector_api.py`):**
    *   A simpler, standalone FastAPI application.
    *   Provides a single endpoint (`/query-to-vector`) that takes a text query and returns its corresponding sentence embedding using the same `all-MiniLM-L6-v2` model. This might be useful for testing or integration with other services that only need the embedding vector.

## Features

*   **Semantic Search:** Find products based on the *meaning* of the query, not just keywords.
*   **Efficient Indexing:** Uses FAISS for fast nearest-neighbor searches on embeddings.
*   **Popularity Ranking:** Search results are boosted based on sales data (`total_items_sold`).
*   **RAG Recommendations:** Leverages Google's Gemini API to provide rich, context-aware recommendations for search results.
*   **Chat Interface:** A conversational endpoint that can handle both book requests and general chat using Gemini for intent recognition and response generation.
*   **Database Integration:** Uses MySQL to store product data and embeddings.
*   **Configurable:** Uses a `.env` file for database credentials and API keys.
*   **Asynchronous API:** Built with FastAPI for high performance.

## Setup & Installation

1.  **Clone the Repository:**
    ```bash
    git clone <your-repository-url>
    cd <repository-directory>
    ```

2.  **Create a Virtual Environment (Recommended):**
    ```bash
    python -m venv venv
    # On Windows
    .\venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **Install Dependencies:**
    Create a `requirements.txt` file with the following content:
    ```txt
    fastapi
    uvicorn[standard]
    pydantic
    python-dotenv
    sentence-transformers
    mysql-connector-python
    numpy
    faiss-cpu  # Or faiss-gpu if you have CUDA installed and compatible hardware
    requests
    tqdm
    psutil
    ```
    Then install them:
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: `faiss-cpu` is generally easier to install. Use `faiss-gpu` for potentially better performance if you have the necessary NVIDIA drivers and CUDA toolkit installed.)*

4.  **Set up MySQL Database:**
    *   Ensure your MySQL server is running.
    *   Create a database (e.g., `printrado_db`).
    *   Create the `PrintradoProducts` table. You'll need at least these columns:
        *   `product_id` (INT, PRIMARY KEY)
        *   `product_name` (VARCHAR/TEXT)
        *   `product_categories` (VARCHAR/TEXT)
        *   `total_items_sold` (INT)
        *   `product_url` (VARCHAR/TEXT)
        *   `image_url` (VARCHAR/TEXT)
        *(The `embeddings.py` script will add `name_embedding` (TEXT) and `category_embedding` (TEXT) columns automatically if they don't exist).*
    *   Populate the table with your product data.

5.  **Configure Environment Variables:**
    Create a `.env` file in the project root directory (`c:\Users\moham\Downloads\LLM\.env`) and add your configuration:
    ```dotenv
    # Database Configuration
    DB_HOST=your_mysql_host (e.g., localhost)
    DB_PORT=your_mysql_port (e.g., 3306)
    DB_NAME=your_database_name
    DB_USER=your_database_user
    DB_PASS=your_database_password
    DB_POOL_SIZE=5 # Adjust as needed

    # Gemini API Configuration
    GEMINI_API_KEY=your_google_gemini_api_key
    GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/models # Or your specific endpoint
    GEMINI_MODEL=gemini-pro # Or the model you intend to use (e.g., gemini-1.5-flash-latest)

    # Optional: Specify paths if not in the root directory
    # FAISS_INDEX_PATH=faiss_index.bin
    # PRODUCT_INFO_PATH=product_info.json
    ```

6.  **Generate Embeddings:**
    Run the embedding script. This will read your product data, generate embeddings, and save them back to the database. This might take some time depending on the number of products.
    ```bash
    python c:\Users\moham\Downloads\LLM\embeddings.py
    ```
    Monitor the console output for progress and any errors.

## Running the Application

1.  **Start the Main Search & Chat API:**
    This command will start the main API server using Uvicorn. The `--reload` flag automatically restarts the server when code changes are detected (useful for development).
    ```bash
    uvicorn c:\Users\moham\Downloads\LLM\search_api_with_sales:app --reload --host 0.0.0.0 --port 8000
    ```
    The API will be available at `http://localhost:8000`. You can access the interactive documentation (Swagger UI) at `http://localhost:8000/docs`.

2.  **Start the Utility Query-to-Vector API (Optional):**
    If you need the standalone embedding service, run it on a different port:
    ```bash
    uvicorn c:\Users\moham\Downloads\LLM\query_to_vector_api:app --reload --host 0.0.0.0 --port 8001
    ```
    This API will be available at `http://localhost:8001`, with docs at `http://localhost:8001/docs`.

## API Endpoints (`search_api_with_sales.py` - Main API)

*   **`POST /search`**
    *   **Request Body:** `{"query": "your search query"}`
    *   **Response:** JSON object containing the original query and a list of `results`. Each result includes product details (`product_id`, `product_name`, `categories`, `total_items_sold`, `product_url`, `image_url`), similarity score, and a `recommendation` string generated by Gemini.
*   **`POST /chat`**
    *   **Request Body:** `{"query": "your chat message or book query"}`
    *   **Response:** JSON object containing the original query and a `response` string. The response will either be a formatted list of book recommendations (if Gemini detected a `BOOK_REQUEST`) or a conversational reply.
*   **`POST /query-to-vector`**
    *   **Request Body:** `{"query": "text to embed"}`
    *   **Response:** JSON object containing the original query, the generated `embedding` (list of floats), and `embedding_length`.

## API Endpoints (`query_to_vector_api.py` - Utility API)

*   **`POST /query-to-vector`**
    *   **Request Body:** `{"query": "text to embed"}`
    *   **Response:** JSON object containing the original query, the generated `embedding` (list of floats), and `embedding_length`.

## Notes

*   The first time the `search_api_with_sales.py` runs (or if `faiss_index.bin` and `product_info.json` are missing), it will build the FAISS index from the database, which might take some time and consume memory depending on the data size. Subsequent runs will load the index from the files, which is much faster.
*   The `LIMIT 1000` in `build_faiss_index_from_db` within `search_api_with_sales.py` is currently set for testing. Remove or adjust this limit to process all your products.
*   Ensure your Gemini API key has the necessary permissions and quotas.
*   The CORS configuration in `search_api_with_sales.py` allows requests from `http://localhost:8080` and `http://localhost:5500`. Adjust this list if your frontend runs on a different origin.
